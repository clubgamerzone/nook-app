# Nook App Review Notes — Beta Draft

## Product description

Nook is a genuine local-first organizer for reminders, medicine schedules, appointments, and notes. It also contains a disclosed, invitation-only one-to-one messaging feature called Private Space.

## Reviewer access

1. Sign in using the review account credentials supplied in the store portal.
2. Open **Settings** from the bottom navigation.
3. Under **Security**, open **Privacy & access**.
4. On first access, create a 4–8 digit local PIN. Biometrics are optional.
5. Use **+** to create or enter a one-time invitation code.

The pre-unlock interface uses neutral privacy language so a casual observer cannot infer what the user keeps behind the local PIN. After successful verification, the messaging feature is identified normally. The feature remains fully documented here and in the product and privacy disclosures.

## Current behavior

- Organizer items are local to the device and can schedule local alerts.
- Chat push notifications are not included.
- The application locks and leaves Private Space when backgrounded.
- Android prevents screenshots while Private Space is open.
- Users can block, report, or remove a contact and can delete their account in Settings.

## Submission gate

Do not submit this beta build as a production privacy messenger. Text transport is visibly identified as development-only until the audited native Signal-protocol adapter and encrypted voice pipeline are completed and independently reviewed.
